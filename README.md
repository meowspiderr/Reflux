# Reflux

Reflux, a simple windows 11 app for easy audio editing. drop a audio file in any format and edit the bass, vocal presence, audio quality, length, and much more!

## Getting started

1. Go to Releases and download the installer.
2. Configure your output folder. Go to settings located in the top right then click the "Browse" button. choose the output folder of your choosing then click "Select folder"
3. Drag your audio file into the dash box or browse for them by clicking the box.
4. Edit your audio file to your desires.
5. Review your changes in the overview section of the audio editor. then click "Export ->" your file will show up in the same format but with your changes.
